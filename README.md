# 🌸 Glow Naturally – Skincare Website

A modern, responsive skincare website inspired by Nykaa-style UI.
Built using **HTML, CSS & JavaScript** in a **single HTML file**.

## ✨ Features
- 💄 Premium skincare product layout  
- 🛍️ Product filter (Serum / Moisturizer / Sunscreen)  
- ❤️ Wishlist (heart icon)  
- 🔍 Quick View product popup  
- 🎨 Smooth animations & hover effects  
- 📱 Fully responsive (mobile friendly)  
- 🌙 Clean & minimal
